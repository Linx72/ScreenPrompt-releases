# ScreenPrompt — установщики

Здесь лежат только собранные установщики ScreenPrompt для macOS и Windows.
**Исходного кода в этом репозитории нет** — разработка ведётся в закрытом репозитории на
[repobase.ru](https://repobase.ru).

Сайт программы: [screenprompt.24oros.ru](https://screenprompt.24oros.ru/).

## Скачать

Все версии — на вкладке [Releases](../../releases).

| Платформа | Файл |
|---|---|
| macOS (Apple Silicon) | `ScreenPrompt_<версия>_aarch64.dmg` или `ScreenPrompt.zip` |
| Windows (x64) | `ScreenPrompt_<версия>_x64-setup.exe` или `ScreenPrompt_<версия>_x64_en-US.msi` |

Предварительные сборки не подписаны: на macOS — правый клик → «Открыть»; на Windows SmartScreen
может предупредить — «Подробнее» → «Выполнить в любом случае».
